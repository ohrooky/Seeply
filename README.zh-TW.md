# Seeply

**Simply see.**

簡約、原生的 macOS 看圖軟體，以看圖體驗為核心。使用 Swift、AppKit 與 SwiftUI 撰寫。

[English](README.md) · 繁體中文

## 功能

- **Lightbox**：暗底沉浸看圖，閒置後淡出控制列。
- **Frameless**：無標題列視窗，上下控制列各自於滑鼠離開 1.5 秒後隱藏，移回對應邊緣時浮現。
- **Window Fit**：視窗配合圖片目前的顯示尺寸，保留圖片倍率，並限制於螢幕可用範圍。
- **精確看圖**：游標位置縮放、觸控板手勢、平移、旋轉、Retina 原始像素與適合視窗。
- **拍攝資訊**：EXIF 面板與可開關的簡易摘要；來源有提供時顯示相機、鏡頭及曝光資訊。
- **主色調色票**：最多四個代表色，提供 HEX 與約略佔比，點擊即可複製。
- **檔案類型篩選**：可選 JPG／JPEG、PNG、BMP、DNG 等一般影像與 RAW 類型；未勾選的格式不加入瀏覽、縮圖與預載隊列。
- **輕量瀏覽**：Finder 開檔、拖放、自然排序、縮圖列、縮圖總覽與多視窗。
- **繁中與英文**：設定內即時切換；系統主要語言為繁中才預設繁中，其餘使用英文。

## 建置與執行

需要 **macOS 14 或以上**與 **Xcode 16 或以上**，無須額外的 Swift 套件。

1. Clone 或下載此儲存庫。
2. 使用 Xcode 開啟 `Seeply.xcodeproj`。
3. 選擇 **Seeply → My Mac**，按 **⌘R**。
4. 開啟圖片、拖入資料夾，或選擇「檔案 → 開啟示範圖片」。

專案使用本機 ad-hoc 簽章；若 Xcode 詢問簽章身分，選擇 **Sign to Run Locally**。內建示範圖為程式繪製的風景插畫。

**v0.1.7 為開發中的原始碼預覽版**，尚未提供完成簽章與公證的 `.app`／`.dmg`。

## 快捷鍵

單鍵快捷鍵適用於照片檢視區。

| 操作 | 快捷鍵 |
|---|---|
| 開啟圖片／資料夾 | ⌘O／⇧⌘O |
| 上／下一張 | ←／→ |
| 圖片適合視窗／原始像素 | 0／1 |
| 視窗配合圖片 | W |
| Lightbox／Frameless | L／B |
| 全螢幕 | F |
| 照片資訊／簡易 EXIF | I／E |
| 主色調色票 | P |
| 縮圖列／縮圖總覽 | T／G |
| 順時針旋轉 | R |
| 設定 | ⌘, |

## 偏好設定

在「**Seeply → 設定… → 檔案類型**」選擇要瀏覽的格式。初次使用預設全選，勾選會保存並立即套用至所有視窗；副檔名不分大小寫，常見別名共用選項。

目前照片仍符合篩選時保留已解碼影像與檢視狀態；被排除時，優先切到下一張符合的照片，沒有下一張才回到上一張。沒有符合圖片時，可直接進入檔案類型設定或恢復所有類型。

在「**一般 → 語系**」選擇跟隨系統、繁體中文或 English。另可設定畫布背景、簡易 EXIF、色票、循環換圖與保留縮放倍率。

## 開發與驗證

在安裝 Xcode 的 Mac 執行原生測試：

```sh
./scripts/check.sh
```

使用 Swift 6.0 以上編譯器執行跨平台核心測試：

```sh
swift test
```

v0.1.7 原始碼快照已通過 **70 個核心測試**，核心亦通過 Swift 6 嚴格併發型別檢查。**12 個原生 macOS 整合／繪圖測試**與完整原生建置仍需在 Mac 驗證；目前沒有宣稱已完成原生 CI 驗證。

詳細資訊見[驗證紀錄](VALIDATION.md)、[開發筆記](DEVELOPMENT.md)與[版本紀錄](CHANGELOG.md)。

## 目前範圍

- 可開啟格式與相機 RAW 相容性取決於 macOS ImageIO；動畫與多頁格式目前只顯示主要靜態影像。
- 資料夾僅掃描當層，外部變更使用 **⌘R** 重新整理；檔案管理功能以輕量為原則。
- 極大型影像有解碼預算限制，尚未實作分塊渲染或 HDR／EDR 輸出。
- 顯示旋轉不修改原始檔；色票取樣整張圖片的縮小預覽，屬於近似代表色。

色票的 Oklab 轉換依 [Björn Ottosson 公開公式](https://bottosson.github.io/posts/oklab/)實作。
