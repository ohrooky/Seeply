# Changelog

## v0.1.7

- Rename the application, Xcode project, targets, scheme and Swift modules to **Seeply**.
- Update English/Traditional Chinese interface names and documentation.
- Preserve the original bundle identifier and preference keys for existing installations.

## v0.1.6

- Add persistent file type filters with common-image and RAW presets.
- Apply changes to all windows, including navigation, thumbnails and preloading.
- Add recovery actions when no files match the selected types.

## v0.1.5

- Independently hide Frameless top/bottom controls after 1.5 seconds.
- Reveal controls on edge hover while preserving the image viewport.

## v0.1.4

- Add English and Traditional Chinese language preferences.
- Default to English unless the primary system language is Traditional Chinese.

## v0.1.3

- Refine the compact toolbar and preserve image zoom with Window Fit.
- Add quick EXIF visibility preferences and representative-color swatches.

## v0.1.2

- Clip large, zoomed images to their canvas so controls remain visible.

## v0.1.1

- Improve decoding cancellation, shared requests, caches and interface feedback.

## v0.1.0

- Initial native image viewer with Lightbox, Frameless, Window Fit and EXIF inspection.
